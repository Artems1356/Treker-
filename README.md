# ⚔️ Quest Board — трекер привычек в стиле RPG

Превращает ежедневные привычки в игру: выполняй квесты, получай опыт и монеты, повышай уровень, держи серию дней и собирай трофеи.

Сделано на чистых **HTML, CSS и JavaScript**: без фреймворков и без сервера.

## 🎮 Возможности

- **Квесты трёх сложностей**: 🟢 лёгкий (+10 XP), 🟡 средний (+20 XP), 🔴 сложный (+35 XP)
- **Уровни и звания**: Новичок → Искатель → Воин → Маг → Магистр → Легенда
- **Экран LEVEL UP** с конфетти и 8-битным звуком
- **Монеты 🪙** и **лавка аватаров**
- **Серия дней 🔥**: сколько дней подряд ты выполняешь квесты
- **12 трофеев**, которые открываются автоматически
- **Круг прогресса** за день и **график опыта** за 7 дней (оси X и Y)
- **Автосохранение** в `localStorage`: прогресс не пропадает после перезагрузки
- Каждый день квесты обновляются
- Адаптивный дизайн: удобно и на телефоне

## 🚀 Запуск

Просто открой `index.html` в браузере.

## 🌐 Публикация на GitHub Pages

1. Создай репозиторий на GitHub и загрузи туда файлы проекта.
2. Открой **Settings → Pages**.
3. В разделе **Source** выбери ветку `main` и папку `/ (root)`, затем нажми **Save**.
4. Через минуту сайт будет доступен по адресу `https://<твой-ник>.github.io/<имя-репозитория>/`.

## 📁 Структура

```
index.html   — разметка страницы
style.css    — неоновый игровой стиль и анимации
script.js    — логика игры (опыт, уровни, трофеи, график, сохранение)
```

HTML5 · CSS3 (Grid, Flexbox, анимации) · JavaScript (DOM, Canvas, SVG, Web Audio API, localStorage)
